# 恒熠聚声 GLEAM · 资讯页

一个纯静态、可直接托管到 GitHub Pages 的资讯子页面。视觉主体是一颗由真实世界陆地数据绘制的金色地球；信息线、圆点扩散与资讯卡由同一个动画状态机统一调度。

> 当前 8 条资讯为可替换的演示文案，正式上线前请替换为团队确认内容。

---

## 快速预览

页面通过 `fetch` 读取本地 JSON，因此不能直接双击 `index.html` 用 `file://` 打开。

### Windows：双击 `preview.cmd`

双击项目根目录的 `preview.cmd`，窗口里会直接打印预览地址：

```text
  预览
  ---------------------------------------------------
    电脑   http://127.0.0.1:8765/
    手机   http://192.168.0.119:8765/
           手机要和这台电脑连同一个 Wi-Fi
  ---------------------------------------------------
```

- 默认 8765 端口，被占用时自动顺延，并按实际端口打印地址；
- 同时监听局域网，手机连同一个 Wi-Fi 就能打开上面的手机地址；
- 自动用默认浏览器打开电脑地址；
- 关闭该窗口（或按 `Ctrl+C`）即停止预览，不留后台进程；
- 手机打不开时，在 Windows 防火墙弹窗里允许「专用网络」访问。

可选参数：

| 命令 | 效果 |
| --- | --- |
| `preview.cmd` | 默认浏览器打开，地址栏可见 |
| `preview.cmd mobile` | 390×844 无地址栏 `--app` 窗口 |
| `preview.cmd desktop` | 1440×900 无地址栏 `--app` 窗口 |
| `preview.cmd --check` | 只打印端口与局域网地址，不启动服务 |

### 其他系统

任意静态服务器均可，例如：

```bash
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。

## 部署到 GitHub Pages

1. 将本目录全部文件上传到仓库（`index.html` 必须在站点根目录）。
2. 在仓库 `Settings → Pages` 中选择对应分支与根目录。
3. 不需要构建步骤；`.nojekyll` 已包含，避免 Jekyll 处理静态资源。
4. 页面使用 hash 路由（`#/article/<id>`），详情页刷新不会 404。

没有运行时 CDN 依赖：D3 与陆地数据都在 `assets/` 内。

## 交互

### 首页设置栏

从左到右：

1. `中文｜EN`：切换语言。两种语言版本算同一条资讯，数字不重复计数。
2. `进行｜停止` / `ON｜OFF`：停止时不再生成新线，已在途的线继续到位；到位不产生新资讯卡；地球不会冻结，而是继续慢漂移。点“进行”恢复生成新线。
3. `快｜中｜慢` / `F｜M｜S`：切换动画时长倍率；慢档约为快档 2 倍时长。
4. `8`：资讯总数，自动读取 `news.json` 中唯一资讯条数。

默认：中文、进行、快。

### 语言切换

- 设置栏文字整体向下滚出，新语言从上方滚入；`｜` 与数字不动。
- 当前正在入场的资讯卡先完成入场，再停顿约 260ms，资讯板块才开始阶梯退场。
- 手机端向左退场，电脑端向右退场。
- 清空后从新语言第一条重新开始。
- 停止状态下也可以切换；切换完成后保持停止，点“进行”后从第一条开始。
- 切换不会重置地球朝向，不会突然跳到另一片大陆。

### 资讯区

- 新资讯永远在最上面，旧资讯向下移动。
- 到达前约 140ms 预先腾出槽位，卡片再快速从右向左入场。
- 用户滚动查看旧资讯时不会自动翻回；空闲 1.5 秒后快速回顶。
- 新卡插入时做滚动补偿，正在阅读的位置不会被顶走。
- 连续循环时同名资讯可能再次出现；DOM 达到 42 张后静默移除最旧一张。

### 地球运动

- 地球在任何可见状态下都不完全静止：开场、到达、停止时都会保留约 4–6°/s 的慢漂移。
- 相机使用临界阻尼弹簧，限制最大角速度与角加速度；没有瞬间大角度跳转。
- 线到达后不会“急刹”在终点，而是保留惯性、平滑收敛到漂移。
- 线到达后先完整停留约 1.6s，再从起点向终点逆生长消失；起点先消失，终点最后消失。
- 起点圆点随回缩淡出；到达圆点在回缩结束后约 700ms 淡出，不会瞬间消失。
- 选择下一条跟踪线时优先距离当前相机较近的线，减少大幅甩动。
- **视觉线路不再使用固定的 8 条资讯 route**：每次从 `assets/data/cities.json` 的全球城市池随机取起点/终点。
- 约 30% 的端点会在城市附近随机偏移（±7° 经度 / ±5° 纬度），并做陆地校验；这是“城市池 + 随机点”，不是全球均匀撒点。
- 线长限制在约 20°–140°，方向随机；上一组刚用过的同一对起终点会跳过。
- 起始资讯、顺序、线路、初始地球朝向每轮重新随机；飞行时长和发射间隔也轻微随机。
- `news.json` 里的 `route` 字段保留作文案参考/备用，不参与当前视觉线路。

### 详情页

- 点击资讯卡进入，默认黑底白字。
- 右上角第一个图标切换明暗；太阳/月亮改为两个独立 `<svg>` 元素，用透明度 + 旋转缩放过渡，月亮为新月轮廓，不使用 mask，减少重绘卡顿。
- 后两个图标位置已预留，接入代码时替换 `.icon-slot` 内容即可。
- 左上角返回；返回后恢复打开前的页面状态与滚动位置。

## 替换资讯

编辑 `assets/data/news.json`：

```json
{
  "stories": [
    {
      "id": "gleam-2026-11-01",
      "date": "2026-11-18",
      "tag": { "zh": "计划", "en": "Programme" },
      "title": { "zh": "中文标题", "en": "English title" },
      "summary": { "zh": "摘要", "en": "Summary" },
      "body": {
        "zh": ["正文第一段", "正文第二段"],
        "en": ["Paragraph one", "Paragraph two"]
      },
      "route": {
        "from": [121.4737, 31.2304],
        "to": [2.3522, 48.8566],
        "fromLabel": "上海",
        "toLabel": "巴黎"
      }
    }
  ]
}
```

- 一个 `story` 同时包含中英文，算 1 条资讯。
- 页面数字自动等于 `stories.length`。
- `route.from` / `route.to` 为 `[经度, 纬度]`，用于地球上的起点与终点。
- 某条缺英文时回退中文，不改变总数。
- 修改后无需改动画代码。
- 视觉线路由 `assets/data/cities.json` 生成；城市池可自行增删，但加入的城市必须落在陆地多边形内，可运行 `node tools/verify-land.mjs` 检查。
- 当前 `route` 字段不参与视觉线路，仅作为文案/备用参考。

`index.html` 的详情页头部：

```html
<span class="icon-slot" data-icon-slot="2" aria-hidden="true"></span>
<span class="icon-slot" data-icon-slot="3" aria-hidden="true"></span>
```

替换为：

```html
<button class="icon-btn" type="button" aria-label="...">
  <!-- 你提供的 SVG / 图标代码 -->
</button>
```

图标统一样式：`24×24` viewBox、`1.6` 描边、圆角端点、颜色继承 `currentColor`，因此会随明暗模式自动变色。清空 `.icon-slot` 内的占位点即可。

## 动画架构

- 只有一个 `requestAnimationFrame` 主循环，位于 `director.js`。
- 两个时间基：
  - `motionTime`：地球相机、线路、扩散、卡片入场；按快/中/慢缩放，不在停止时冻结。
  - `uiTime`：语言滚轮、卡片退场、自动回顶；按界面节奏推进。详情页明暗过渡由 CSS 状态驱动。
- 所有 mission 的开始/到达/脉冲/卡片槽位都由 `Director.tick()` 计算。
- 没有 `setTimeout` / `setInterval` 驱动动画。
- 地球使用 D3 正交投影对 Natural Earth 110m 陆地做半球裁剪与金色填充。
- 相机同一时刻只跟踪一条信息线；其他线可并行穿过可见半球，端点扩散仅在可见时播放。
- 相机为临界阻尼弹簧：`stiffness=16`、`damping=8`、最大角速度 `1.3 rad/s`、最大角加速度 `5.5 rad/s²`。

### 陆地数据说明

- 陆地来自 Natural Earth `ne_110m_land`，是标准公共领域地理数据，不是手绘。
- 大陆、主要半岛和主要岛屿正确；110m 会简化极小岛、窄海峡和细碎海岸线。
- 地球不绘制国界、国家名或城市名，只显示陆地轮廓，避免政治边界/名称标错。
- 所有 route 端点与参考城市已用 `tools/verify-land.mjs` 检查，均落在陆地多边形内：

```bash
node tools/verify-land.mjs
```

- 如果未来需要更精细海岸线，可换 50m/10m 数据；体积和每帧绘制成本会上升。

状态机、优先级与时序详见：[方案与动画状态机.md](方案与动画状态机.md)。

## Windows 预览脚本

双击 [preview.cmd](preview.cmd) 即可，不需要安装 Python 或 Node：

```text
  预览
  ---------------------------------------------------
    电脑   http://127.0.0.1:8765/
    手机   http://192.168.0.119:8765/
           手机要和这台电脑连同一个 Wi-Fi
  ---------------------------------------------------
```

- 自动从 8765 起挑选一个空闲端口，并监听 `0.0.0.0`，所以手机地址可直接访问；
- 电脑地址用默认浏览器打开；`mobile` / `desktop` 参数改用 Edge/Chrome 的无地址栏 `--app` 窗口；
- 关闭窗口或按 `Ctrl+C` 即停止；服务不会残留到后台；
- 手机档是 390×844 窗口，不是真机 UA 模拟；页面本身只依赖宽度媒体查询，所以移动布局会生效。

命令行自检：

```bat
preview.cmd --check
```
